# S3 Viewer

A desktop app for browsing OpenStack and other S3 buckets. Open files, change them, and move them between your machine and the bucket.

![Dark and light mode](<misc/Dark and light mode comparison.png>)

## Features

- 💾 Save connections
- 🗂️ Double-click through folders
- 🔎 Filter by name
- ✏️ Open and edit files right there — txt, yaml, xml, json, csv, and tiff
- ⬆️⬇️🗑️ Upload, download, and delete files and folders
- 🌙☀️ Light and dark mode

## Start

```bash
./start.sh
```

The first launch creates a virtual environment and installs the dependencies. You can also start it from the application menu or by double-clicking `S3 Viewer.desktop`.
